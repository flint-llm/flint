# Security Policy

## Reporting a Vulnerability

To report a security vulnerability in Flint, please email the maintainers directly rather than opening a public GitHub issue.

Contact: open a private security advisory via GitHub Security Advisories on this repository.

Include:
- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any suggested mitigations

We will acknowledge your report within 72 hours and provide a timeline for a fix.

Do not disclose the vulnerability publicly until a patch has been released.
